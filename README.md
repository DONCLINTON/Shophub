# 🛍️ ShopHub – Simple Marketplace

A lightweight, Jumia‑style marketplace where users can browse listings by category, search for products, and sell items by posting a photo, price, and WhatsApp contact. Built as a single‑page HTML application with **Supabase** for storage and database.

## ✨ Features

- 📂 **12+ categories** – Electronics, Phones, Fashion, Home & Kitchen, Beauty, Sports, Books, Automotive, Toys, and more.
- 🔍 **Search & filter** – Real‑time filtering by category or keyword.
- 📸 **Image upload** – Sellers upload product photos directly to Supabase Storage.
- 💬 **WhatsApp integration** – Buyers contact sellers instantly with a single tap.
- ⚡ **Responsive** – Works on desktop, tablet, and mobile.
- 🚀 **Fast & zero‑config** – No build tools required; just open `index.html`.

## 🛠️ Tech Stack

- **Frontend** – HTML + Tailwind CSS (via CDN)
- **Backend & Storage** – Supabase (PostgreSQL, Storage, Auth-ready)
- **JavaScript** – Vanilla ES6 with Supabase JS client

SHOPHUB UG — SOURCE FIXES APPLIED

1) PHONE NUMBER HANDLING
- Phone numbers are normalized to E.164 format for storage and display.
- Example: +256744343456 remains +256744343456; a local 0744343456 is stored as +256744343456.
- WhatsApp links intentionally remove the plus sign because wa.me expects the international number as digits only.
- Applied to seller listing submissions, seller contact links, employer WhatsApp links and job applications.
- Existing database rows are not bulk-modified. Existing numbers are normalized when displayed/used; newly submitted/updated values use E.164.

2) INDEXING / SEO
- Added a Netlify Edge Function for /product/* and /jobs/* that injects route-specific title, description, canonical URL and structured data into the initial HTML response.
- This addresses the root-shell canonical issue: deep product/job URLs no longer initially declare the homepage as canonical.
- Added a dynamic /sitemap.xml generated from current Supabase listings and jobs, so new listings/jobs appear automatically.
- Kept robots.txt allowing crawling and pointing to the sitemap.
- Updated the service-worker cache version to v6.
